Barcode & QR Generator

Boleh jana QR code atau Code 128 barcode. Masukkan teks/URL di bawah dan pilih jenis, kemudian tekan "Generate".

Sumber: menggunakan JsBarcode untuk Code128 dan qrcodejs untuk QR.

Untuk publish ke web (GitHub Pages): buka Settings > Pages dalam repo, pilih branch main dan folder / (root), simpan. Laman akan tersedia di https://.github.io/bye2/ dalam beberapa minit.
